# Contributing

This repository is primarily a public technical showcase.

Before contributing:

1. Do not add customer or client data.
2. Do not commit credentials or tokens.
3. Use TechTurn synthetic demo identities only.
4. Keep examples read-only unless a change workflow is explicitly documented.
5. Keep screenshots and generated artifacts sanitized.
6. Preserve the public product story: Connect → Discover → Model → Classify → Map → Assess → Report.
