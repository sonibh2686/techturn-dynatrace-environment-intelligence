# Interactive Environment Layer Report

This directory is reserved for the public synthetic TechTurn demo of the Environment Layer Report.

The production platform can generate much larger environment reports, but customer-generated reports are intentionally not included in this repository.

Planned demo identity:

- Environments: DEV / QA / PERF / PROD
- Applications: PaymentsPortal, CustomerPortal, TechTurn Digital Platform
- Hosts: tt-app-01, tt-app-02, tt-api-01, tt-db-01
- Services: payment-service, customer-service, gateway-service
- Business service: TechTurn Digital Payments

The public demo will preserve the navigation and relationship model while using fully synthetic data.
